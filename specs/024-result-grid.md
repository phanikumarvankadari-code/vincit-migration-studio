# SPEC-024: Transformed Result Grid

## Status
Draft

## Objective
Display transformed target records inside the application.

## Requirements
- Display target structures.
- Filter Ready / Warning / Error.
- Support large datasets through appropriate virtualization/paging.
- Allow cell selection for lineage.
- Allow row inspection.
- Preserve target field metadata.

## Acceptance Criteria
User can inspect transformed data without exporting Excel.

## Out of Scope
- Excel editing
